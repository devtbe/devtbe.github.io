# devtbe.github.io

Il sito di devtbe, pubblicato con GitHub Pages.

- `index.html` — pagina principale con l’elenco delle app
- `proverbs/` — la pagina di Detti e proverbi / Idioms & Proverbs (ex Verba volant), in inglese
- `proverbs/privacy/` — l’informativa sulla privacy, in inglese (da indicare nella Play Console; cancellazione dati: `#cancel`)
- `verbavolant/` e `verbavolant/privacy/` — solo rinvii automatici ai nuovi indirizzi (i vecchi link continuano a funzionare)
- `assets/` — stile comune e icone

Per aggiungere un’app: crea una cartella con il suo nome (es. `nuovaapp/index.html`) e aggiungi una scheda in `index.html`.
